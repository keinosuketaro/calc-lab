# Python コーディングルール

## 書き方
1. すべての関数に型ヒントと、1行目が要約の docstring を付ける
2. 不正な入力は ValueError を送出し、メッセージに「何がどう不正か」を日本語で書く
3. 1つの関数は1つの仕事に絞る（目安30行以内）

## テスト
- 実装と同時に pytest のテストを書く。正常系・境界値・異常系を最低1つずつ
- テスト名は `test_何を_どうすると_どうなる` の形にする
- テストを実行し、結果の出力を見せてから完了とする。理由：「できたはず」ではなく証拠で確認するため

## 完了の報告
最後に、作ったファイル・テストの件数と結果・気になった点を3行でまとめる。
